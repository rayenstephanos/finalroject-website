What is the Internet?

ما هو الإنترنت؟

The Internet is a global system of interconnected computer networks that use standardized communication protocols to link billions of devices worldwide. It is not a single network but rather a vast "network of networks" — a decentralized infrastructure that allows computers, smartphones, servers, and other devices to communicate with each other across the planet.

الإنترنت هو نظام عالمي من الشبكات الحاسوبية المترابطة التي تستخدم بروتوكولات اتصال موحّدة لربط مليارات الأجهزة حول العالم. إنه ليس شبكة واحدة، بل بنية تحتية لامركزية هائلة تتيح للأجهزة التواصل عبر الكوكب.

Key insight

The Internet and the World Wide Web are NOT the same thing. The Internet is the physical infrastructure; the Web is one of many services that runs on top of it.

الإنترنت والشبكة العنكبوتية العالمية ليسا الشيء ذاته. الإنترنت هو البنية التحتية المادية؛ والويب هو أحد الخدمات التي تعمل فوقها.

At its core, the Internet is built on the TCP/IP protocol suite, which defines how data is transmitted, addressed, routed, and received. This architecture is intentionally robust — data can take many paths between two points, so the network can survive partial failures.

في جوهره، يُبنى الإنترنت على مجموعة بروتوكولات TCP/IP التي تحدد كيفية نقل البيانات وعنونتها وتوجيهها واستقبالها. هذه البنية متينة عمداً — إذ يمكن للبيانات سلوك مسارات متعددة بين نقطتين.

02

History & Origins

التاريخ والأصول

The Internet grew from ARPANET, a project funded by the US Department of Defense in the late 1960s. Its original purpose was to create a communication network resilient enough to survive a nuclear attack. Over decades, it evolved from a military and academic network into the global commercial and social infrastructure we use today.

نشأ الإنترنت من شبكة ARPANET، وهو مشروع موّلته وزارة الدفاع الأمريكية في أواخر ستينيات القرن الماضي. وعلى مدى عقود، تطوّر من شبكة عسكرية وأكاديمية إلى البنية التحتية الاجتماعية والتجارية العالمية التي نستخدمها اليوم.

1969
ARPANET launched — first message sent between UCLA and Stanford, though the system crashed after two letters.
1973
TCP/IP conceived by Vint Cerf and Bob Kahn — the foundational protocol that makes the modern Internet possible.
1983
DNS introduced — the Domain Name System replaced numeric IP addresses with human-readable names like google.com.
1991
World Wide Web born — Tim Berners-Lee published the first website and made the Web publicly available.
1995
Commercialization — NSFNet backbone decommissioned; Internet opened fully to commercial traffic.
2007
Mobile Internet — the iPhone launch sparked the smartphone era, putting the Internet in everyone's pocket.
2024
5.5 billion users — over 67% of the world's population is now connected to the Internet.
03

How the Internet Works

كيف يعمل الإنترنت

When you type a URL in your browser, a remarkable chain of events unfolds in milliseconds. Your request travels from your device through your ISP (Internet Service Provider) to a series of routers that forward it across the globe, reaching the destination server which sends back the requested data in packets.

عندما تكتب عنوان URL في متصفحك، تنكشف سلسلة رائعة من الأحداث في أجزاء من الثانية. ينتقل طلبك من جهازك عبر مزود خدمة الإنترنت إلى سلسلة من الموجّهات (Routers) التي تعيد توجيهه عبر العالم.

Data Packets & Routing

حزم البيانات والتوجيه

Data is broken into small chunks called packets. Each packet carries a piece of your data plus a header containing source/destination IP addresses, packet sequence number, and error-checking data. Routers examine each packet's destination and decide the best path forward — independently of other packets in the same message.

تُقسَّم البيانات إلى أجزاء صغيرة تُسمى الحزم. تحمل كل حزمة جزءاً من بياناتك بالإضافة إلى رأس يحتوي على عناوين IP المصدر والوجهة ورقم تسلسل الحزمة وبيانات التحقق من الأخطاء.

Did you know?

A single webpage load can involve 50–100 separate HTTP requests, each potentially taking a different physical route across the globe and reassembling perfectly at your browser.

قد يتضمن تحميل صفحة ويب واحدة 50–100 طلب HTTP منفصل، وقد يسلك كل منها مساراً مادياً مختلفاً عبر العالم ليُعاد تجميعها بشكل مثالي في متصفحك.

04

The World Wide Web

الشبكة العنكبوتية العالمية

The World Wide Web, invented by Tim Berners-Lee in 1989 at CERN, is a system of interlinked hypertext documents accessed via the Internet. It uses HTTP (HyperText Transfer Protocol) to transfer web pages written in HTML, and URLs (Uniform Resource Locators) to identify resources.

الشبكة العنكبوتية العالمية، التي اخترعها تيم بيرنرز-لي عام 1989 في CERN، هي نظام من المستندات النصية التشعبية المترابطة يُتاح عبر الإنترنت. تستخدم بروتوكول HTTP لنقل صفحات الويب المكتوبة بـHTML.

Web 1.0 → Web 3.0

من ويب 1.0 إلى ويب 3.0

Web 1.0 (1991–2004) — static, read-only pages. Websites were simple HTML documents with no interactivity. Users consumed content but could not contribute.

Web 2.0 (2004–present) — the social, interactive web. Platforms like Facebook, YouTube, and Wikipedia empowered users to create content. AJAX, JavaScript frameworks, and REST APIs enabled dynamic experiences.

Web 3.0 (emerging) — the decentralized, semantic web. Blockchain technology, NFTs, and AI promise a web where users own their data and machines understand context.

ويب 1.0 (1991–2004) — صفحات ثابتة للقراءة فقط. ويب 2.0 (2004–الآن) — الويب الاجتماعي التفاعلي. ويب 3.0 (قادم) — الويب اللامركزي الدلالي.

Key Protocols

البروتوكولات الأساسية

Protocols are agreed-upon rules that govern how data is transmitted. The Internet runs on dozens of specialized protocols, each handling a specific layer of communication:

البروتوكولات هي قواعد متفق عليها تحكم كيفية نقل البيانات. يعمل الإنترنت على عشرات البروتوكولات المتخصصة:

Transport
TCP/IP
Transmission Control Protocol / Internet Protocol. The foundational suite for all Internet communication.
Application
HTTP / HTTPS
HyperText Transfer Protocol. Defines how web browsers and servers exchange web pages. HTTPS adds encryption.
Application
DNS
Domain Name System. Translates human-readable domain names into IP addresses computers can route to.
Application
SMTP / IMAP
Simple Mail Transfer Protocol and Internet Message Access Protocol. Power the global email system.
Application
FTP / SFTP
File Transfer Protocol. Used to upload and download files between client and server systems.
Security
TLS / SSL
Transport Layer Security. Encrypts all data in transit, forming the basis of the padlock icon in browsers.
06

The Future of the Internet

مستقبل الإنترنت

The Internet continues to evolve at a breathtaking pace. Several major trends are shaping what the network will look like over the next decade:

يستمر الإنترنت في التطور بوتيرة مذهلة. تشكّل عدة اتجاهات رئيسية مستقبل الشبكة خلال العقد القادم:

IPv6 Adoption

The Internet is running out of IPv4 addresses (only ~4.3 billion possible). IPv6 provides 340 undecillion addresses — enough for every grain of sand on Earth to have its own IP.

Internet of Things (IoT)

Billions of everyday objects — from refrigerators to traffic lights — are connecting to the Internet, creating a hyper-connected world that generates unprecedented volumes of data.

Artificial Intelligence Integration

AI is transforming how we interact with the Internet — from intelligent search and content recommendation to autonomous agents that browse and act on our behalf.

يُعيد الذكاء الاصطناعي تشكيل طريقة تفاعلنا مع الإنترنت — من البحث الذكي إلى الوكلاء المستقلين الذين يتصفحون الشبكة نيابةً عنا.

Looking ahead

By 2030, analysts estimate there will be over 29 billion connected devices worldwide — nearly four devices for every person on Earth. The Internet is no longer just a human network; it is becoming the nervous system of our entire civilization.

بحلول عام 2030، يُقدّر المحللون أن يكون هناك أكثر من 29 مليار جهاز متصل حول العالم. لم يعد الإنترنت مجرد شبكة بشرية؛ بل أصبح الجهاز العصبي لحضارتنا بأسرها.
